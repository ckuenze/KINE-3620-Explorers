# Walking Gait Phase Explorer

Scrub through one full walking gait cycle of the right limb and name the phase and sub-phase at each point. A two-leg picture shows where both feet are and how the whole-body center of mass (COM) rises and falls.

- **Topic:** Gait cycle phases and sub-phases
- **Use:** Pre-class and in-class (mode switch; `?mode=pre` or `?mode=in`)
- **Unit:** Unit 2: Introduction to Human Movement (Lecture 10)

## Learning objectives

After using this tool, students should be able to:

- Divide the walking gait cycle into stance (about 60%) and swing (about 40%).
- Name the seven sub-phases in order (loading response, midstance, terminal stance, pre-swing, initial swing, mid swing, terminal swing) and say roughly where each falls.
- Treat initial contact (0%) and toe off (60%) as events, and find the two double-support windows (0–10% and 50–60%).
- Define step length, stride length, and cadence, and use speed = step length × step frequency.

## How to use it

Open `index.html` in a web browser. Pick a mode at the top.

- **Pre-class:** guided steps and check questions for the reading's "Before class" list.
- **In-class:** partner predict-then-test challenges, a **Hide names** quiz button, and discussion questions.
- Drag the slider (or use the arrow keys), or press **Play**, to move through the cycle.
- **Prev / Next sub-phase** jumps to the start of each sub-phase.
- Add `&embed=1` to the URL to hide the tool's own mode buttons (used by the Unit 2 Explorer).

## Phase scheme (shared by all Unit 2 gait tools)

Initial contact (event, 0%), loading response 0–10%, midstance 10–30%, terminal stance (heel off) 30–50%, pre-swing (push off) 50–60%, toe off (event, 60%), initial swing 60–73%, mid swing 73–87%, terminal swing 87–100%.

## Details

- **File:** `index.html` (standalone; loads Google Fonts)
- **Data:** Sub-phase boundaries are typical textbook (Rancho Los Amigos style) values, not measured data. The leg and COM motion is an illustrative drawing.
- **Accessibility:** labeled slider with spoken values, live announcements of the sub-phase, text alternative for the drawing, keyboard focus outlines, stance vs swing shown by pattern and text as well as color.
