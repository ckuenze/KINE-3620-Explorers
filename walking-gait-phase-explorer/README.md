# Walking Gait Phase Explorer

Scrub through one full walking gait cycle of a single limb and name the phase and sub-phase at each point.

- **Topic:** Gait cycle phases and sub-phases
- **Use:** Pre-class
- **Unit / week:** [UNIT]

## Learning objectives

After using this tool, students should be able to:

- Divide the walking gait cycle into stance (~60%) and swing (~40%).
- Name the eight sub-phases in order and say roughly where each falls in the cycle.
- Describe what the limb is doing in each sub-phase.
- Define step length, step width, stride length, and cadence.

## How to use it

Open `index.html` in a web browser.

- Drag the slider, or press **Play**, to move through the cycle.
- **Prev / Next sub-phase** jumps to the start of each sub-phase.
- The pendulum figure shows the leg's orientation and the whole-body center of mass.

## Things to notice

- Where stance ends and swing begins (60% of the cycle).
- How much of the cycle is spent in each sub-phase. Midstance and propulsion take up most of stance.
