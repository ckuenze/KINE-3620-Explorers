# Moment Arm Explorer

Use the elbow as a model to see how a single joint angle changes both the internal (muscle) and external (segment weight) moment arms, and why torque changes across the range of motion even when force stays the same.

- **Topic:** Moment arms and torque vs. joint angle
- **Use:** Pre-class
- **Unit:** Unit 2: Introduction to Human Movement

## Learning objectives

After using this tool, students should be able to:

- Define the moment arm as the perpendicular distance from the joint center to a force's line of action.
- Explain why the external (weight) moment arm follows d = L × sin(θ).
- Describe how the muscle moment arm changes across the range of motion.
- Predict whether net torque at a given angle produces flexion or extension, with muscle force and segment weight held constant.

## How to use it

Open `index.html` in a web browser.

- Drag the **joint angle** slider (0° = forearm hanging straight down, 150° = fully flexed).
- Set the **muscle force** and **segment weight**. Both stay constant across all angles.
- **Window 1** shows how each moment arm changes with angle.
- **Window 2** shows internal vs. external torque and which one wins.
