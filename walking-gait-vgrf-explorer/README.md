# Walking Gait vGRF Explorer

Explore the vertical ground reaction force (vGRF) curve across one stance phase of walking, and see how it changes with walking speed.

- **Topic:** Ground reaction forces in walking
- **Use:** In-class
- **Unit / week:** [UNIT]

## Learning objectives

After using this tool, students should be able to:

- Identify the key features of the walking vGRF curve: stance duration, load acceptance peak, propulsion peak, and loading rate.
- Explain when vGRF is above, equal to, and below body weight.
- Describe how faster walking changes the vGRF peaks and the midstance dip.
- Explain why the anterior–posterior GRF is braking in early stance and propulsive in late stance.
- Recognize single and double support when both limbs' vGRF curves are shown together.

## How to use it

Open `index.html` in a web browser.

- Choose **Slow / Normal / Fast** walking speed.
- Drag the slider to move through stance. The readout shows % stance and vGRF.
- Click a feature (**A–D**) to highlight it on the curve.
- Switch units between **BW** and **N** (set body mass with the slider).
- Toggle on the **bilateral** panel (both feet across a full gait cycle) and the **horizontal GRF** panel.
- Open the **Discussion prompts** at the bottom for in-class questions.
