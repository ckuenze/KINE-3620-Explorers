# Running Gait Cycle Explorer

Compare walking and running in two ways: how the gait cycle is structured (double support vs. float phase), and how the ground reaction force curve changes shape, including the impact transient seen with a rearfoot strike.

- **Topic:** Walking vs. running mechanics
- **Use:** [PRE/IN]
- **Unit / week:** [UNIT]

## Learning objectives

After using this tool, students should be able to:

- Explain why walking has a double-support phase and running has a float phase.
- Describe how stance time shrinks as running pace increases.
- Compare the vGRF curves of walking, forefoot-strike running, and rearfoot-strike running.
- Identify the impact transient, the propulsive peak, and loading rate on a running GRF curve.
- Explain why comparing curves by % of stance differs from comparing them in real time.

## How to use it

Open `index.html` in a web browser.

- Use the **Running pace** slider. It changes both the gait-cycle bars and the running GRF curves.
- Toggle each curve (walking, forefoot, rearfoot) on and off.
- Switch the x-axis between **% of stance** and **time (s)**.
- Click **Impact transient**, **Propulsive peak**, or **Loading rate** to highlight that feature.
