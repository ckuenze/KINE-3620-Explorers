How scoring works

Each event is won by the lowest median reaction time. Tied times split the points for those places.

Total = points from every counted event, minus the penalty for each wrong response or early press in the results code. Ties on total go to the athlete with the lower average time across counted events.

Fair racing. Keyboards, touchscreens, and mice add different delays. If the class used mixed devices, use the division buttons on the scoreboard (Keyboard, Touch, Mouse) to crown a winner in each division, or have everyone run on the same machine.
