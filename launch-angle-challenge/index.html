The physics

Once the ball leaves the hand, only gravity (and air, if drag is on) acts on it. Its path is set entirely by release speed v, release angle θ, and release height h.

x(t) = v·cosθ·t
y(t) = h + v·sinθ·t − ½·g·t²   (g = 9.81 m/s²)
Range: R = (v·cosθ / g) · ( v·sinθ + √(v²·sin²θ + 2gh) )
Best angle (no drag): sinθopt = 1 / √(2 + 2gh/v²)  → 45° only when h = 0

Four facts to take away

1. 45° is a special case. It is the best angle only when the ball is released and lands at the same height, with no air drag. Release from above the ground and the best angle drops below 45°.

2. Speed matters most. Range grows with speed squared. Double the release speed and the range roughly quadruples (exactly, when h = 0). Near the best angle the curve is flat on top, so a few degrees off costs very little.

3. Real athletes trade speed for angle. People can't throw as fast upward as they can straight ahead, so release speed falls as release angle rises. That pushes the best angle lower still, and the best angle depends on the athlete (Linthorne NP. Optimum release angle in the shot put. J Sports Sci 2001;19:359–72. doi:10.1080/02640410152006135). The k value here is an illustrative model, not a measurement.

4. Accuracy has two answers. If the throw is fast enough, two angles reach any target: a flat line drive and a high lob. The flat one gets there sooner, which is why fielders throw on a line.
